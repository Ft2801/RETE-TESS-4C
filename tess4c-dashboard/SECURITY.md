# Sicurezza

Applicazione statica. Non elabora credenziali e non espone un backend proprio.

Le letture arrivano dall'API pubblica STARS4ALL. Lo snapshot in repository è un fallback, non un canale autenticato.

## Segnalazione

Per una vulnerabilità relativa a questo codice:

1. Non aprire una issue pubblica con dettagli sfruttabili.
2. Usare la segnalazione privata messa a disposizione dalla piattaforma di hosting del repository.
